# StrainerSetup: upright tea strainer

Scope: the tea strainer placed in the bowl.

The pinned success predicate requires the tea strainer to be upright using
`check_obj_upright` with absolute roll and pitch each less than 30 degrees. Inspect
its standing orientation after release using fresh public views; being inside the
bowl alone does not establish this posture. This is a posture reference, not a
measurement of hidden orientation or a complete task checklist. The task language
already requests upright placement.
