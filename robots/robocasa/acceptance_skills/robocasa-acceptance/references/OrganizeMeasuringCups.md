# OrganizeMeasuringCups: upright cups

Scope: all three measuring cups, not just the last cup moved.

The pinned success predicate checks upright posture for the small, medium and
large measuring cups separately. Each uses `check_obj_upright` with absolute roll
and pitch each less than 60 degrees. Inspect all three cups' standing orientation
after release using fresh public views; a correctly ordered row alone does not
prove posture. This note covers only upright posture and is not a measurement of
hidden orientation or a complete task checklist. The task language also requests
upright cups.
