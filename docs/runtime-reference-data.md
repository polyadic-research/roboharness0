# Frozen runtime reference inputs

The selected 2.0 / Xiaomi runtime reads its original capability catalogs and policy guides as model-bound inputs. Their retained bytes and hashes remain fixed in the publication source boundary. Removing unused integrations does not authorize editing the prompts or reference text used by the RoboCasa/Xiaomi path.

The Xiaomi guidance records calibration on **65 atomic tasks with 15 episodes each** and **five composite tasks with five episodes each**, dated **2026-10-12–2026-10-13**. These fixed priors are separate from the published [selected200 results](../results/2.0-selected200/REPORT.md). Their measurement counts, historical identifiers and evidence pointers describe the original calibration; raw calibration archives remain external.

Fixed priors must remain disclosed when discussing memory or generalization. This source preparation does not independently certify the absence of all dynamic cross-episode state. It does not add calibration outcomes to selected200 or run new calibration.

The [Xiaomi setup](policy-setup.md) supplies the current installation instructions. Historical machine paths inside model-bound text remain original provenance and should not be treated as local installation paths. Changing reference text or runtime protocol requires a separately identified scientific change and appropriate validation.
